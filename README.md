# UniCore

A modern college platform built as a student project for the **Web Development** subject.

UniCore is a ground-up replacement for our institution's Moodle-based platform, which suffers from slow page loads, poor mobile responsiveness, and a confusing user experience. Our goal is a fast, accessible, and genuinely pleasant platform for the people who use it every day: students and teachers.

> **Status:** early development — scope and architecture are still being defined.

---

## Core features (MVP)

- **Authentication & roles** — student, teacher, admin
- **Courses** — enroll, browse enrolled courses, view course overview
- **Materials** — upload and download files, organized by course and topic
- **Assignments** — create, submit, and grade, with file uploads
- **Deadlines dashboard** — one feed of everything due, across all courses
- **Announcements** — per-course news from teachers
- **Responsive UI** — usable down to a 360px-wide viewport

### Explicitly out of scope (for now)

- Real-time video classes or conferencing
- Integration with the institution's real SIS / grade database
- Native mobile apps
- Offline mode

These are candidates for a later phase, not MVP.
